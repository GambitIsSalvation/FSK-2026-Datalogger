### Data Logger

### Currently Implemented Features:
- FreeRTOS
- GPS NMEA parsing ( GPS 10Hz )
- CAN Communication Infrastructure ( 500kbps )
- microSD Write Functionality 
- RTC ( Syncronized with UTC from GPS )

### Unable Features:
- MPU9250 IMU data acquisition ( ACC 200Hz, GYRO 200Hz, MAG 100Hz)
  Currently we are going to change imu sensor.
